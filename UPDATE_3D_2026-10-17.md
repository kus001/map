# kmaps 3D rendering maintenance — 2026-10-17

This update is based on the `map(20261017-224705).zip` source and the supplied developer-console log.

## Changes

- Globe now has a near-black backdrop to show space around Earth at low zoom. MapLibre draws this region transparently: the backdrop must belong to the map DOM container.
- AWS Terrarium DEM tiles are attached to every 3D base style (street / satellite / hybrid). Terrain is loaded when zoomed in: z>=8 in flat mode or z>=12 for the globe, to avoid globe terrain/fog warnings and needless worldwide elevation requests.
- Building extrusions reuse an existing vector source where available; otherwise the fallback vector source is added without adding per-building meshes. Buildings only appear at z>=16.5, avoiding expensive city-scale draws.
- Added a Buildings on/off toggle. On devices reporting <=4GB device memory, it defaults off.
- Reduced rendering overhead by disabling multisample antialiasing, disabling world-copy rendering, setting a bounded tile cache and removing tile fade transitions.
- Added OpenFreeMap style JSON cache; theme/style changes no longer re-fetch an identical free style.
- Added fallbacks for two missing sprite-image IDs reported in the log, and replaced malformed null label sizes in a provider's Sea labels layer.
- Reduced transient 2D provider fallback errors by ignoring normal aborted sprite fetches during mode switching.
- A selected Ontario 511 camera popup refreshes its still imagery at roughly 30-second intervals (while open); it does not pretend a snapshot is live video.
- Fixed an unused variable that caused lint to fail.

## Testing / limitations

- ESLint passed, JavaScript/JSX parsing passed for all source files, Python compilation checks passed.
- The supplied frontend/node_modules contains Windows-native binaries, so a Linux-host Vite build cannot run against it. Install the proper platform's dependencies locally with `cd frontend && npm ci`, then `npm run build`.
- External map styles, AWS elevation tiles, and camera services require network access when you run the app. Visual/performance behaviour on your own computer has not been measured.
- All three 3D styles support raised terrain. The 2D Leaflet view remains flat by design.
- Fully live traffic-video streams from Ontario public authorities have not been verified, so no unsupported video feed was added.

## Run

Keep your original `.env` and `frontend/.env` configuration locally (secrets are intentionally not bundled).

From the `map` folder:

```sh
cd frontend
npm ci
npm run dev
```

Run `python main.py` from the parent `map` folder in a second terminal.
